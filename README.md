# Hypeland Build Kit releases

This public repository is reserved for official Hypeland Build Kit release
metadata and distributable packages. The source repository remains private.

The first early release supports Windows x64 and Linux x64:
[Download Build Kit 0.1.1](https://github.com/jwandroph/hypeland-build-kit-releases/releases/tag/v0.1.1).
It requires Node.js 22.12 or later with npm. Download and extract the installer
ZIP, then run the Windows or Linux installer included in it. macOS is not yet
supported. The source repository remains private; downloadable application
packages include the code required to run Build Kit and synthetic preview data.
